# Машинное обучение в задачах распознавания тональности текста

Курсовая работа (2 курс, бакалавриат «Прикладная математика и информатика», Финансовый университет).

Проект посвящён классификации эмоций в коротких английских текстах классическими методами машинного обучения. Весь код и выводы находятся в одном ноутбуке: [`sentiment_analysis_ml.ipynb`](sentiment_analysis_ml.ipynb).

## О задаче

По тексту предложения нужно определить, какая эмоция в нём выражена. Это задача многоклассовой классификации с шестью классами:

| Метка | Эмоция   |
|:-----:|----------|
| 0     | sadness  |
| 1     | joy      |
| 2     | love     |
| 3     | anger    |
| 4     | fear     |
| 5     | surprise |

## Данные

Датасет `data_emotions.csv` содержит ~18 000 коротких английских текстов с двумя столбцами: `text` и `label`. Пропусков в данных нет.

## Ход работы

1. **Предобработка данных**
   - анализ датасета: размер, длина текстов, распределение эмоций;
   - удаление полных дубликатов (одинаковый текст и одинаковая эмоция). Одинаковые тексты с разными эмоциями оставлены, так как предложение может выражать несколько эмоций;
   - токенизация (`nltk.word_tokenize`);
   - удаление стоп-слов;
   - лемматизация (`WordNetLemmatizer`).
2. **Разделение выборки**: 80% на обучение, 20% на тест (`random_state=42`).
3. **Векторизация**: TF-IDF (`TfidfVectorizer`).
4. **Обучение моделей** (каждая в виде `Pipeline` с TF-IDF).
5. **Подбор гиперпараметров** лучшей модели через `GridSearchCV` (5-fold кросс-валидация).

## Результаты

Метрика — accuracy.

| Модель                        | Train, % | Test, % |
|-------------------------------|---------:|--------:|
| Логистическая регрессия       | 94.87    | 86.14   |
| Метод опорных векторов (SVC)  | 99.19    | 85.20   |
| Метод ближайших соседей (k=10)| 85.87    | 79.73   |
| Наивный байесовский классификатор (alpha=0.2) | 91.42 | 75.67 |
| Дерево решений (max_depth=45) | 51.64    | 46.40   |

Лучшей моделью оказалась **логистическая регрессия**. После подбора гиперпараметров (`max_df=0.9`, `min_df=1`, `C=10`) точность на тесте выросла с 86.14% до **87.81%**.
